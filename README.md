# Venda de Espetinhos - Projeto

Sistema simples de **venda e cadastro de espetinhos** desenvolvido com **PHP, MySQL e Bootstrap** para fins de estudo em desenvolvimento web.

O projeto permite **cadastrar espetinhos, visualizar produtos, realizar compras e registrar pagamentos**, simulando um pequeno sistema de vendas online.

---

## 🚀 Funcionalidades

✔ Cadastro de espetinhos  
✔ Listagem de produtos disponíveis  
✔ Visualização de detalhes do produto  
✔ Simulação de compra

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com objetivo **educacional**, para praticar conceitos importantes de programação web, como:

* conexão com banco de dados utilizando **PDO**
* uso de **classes e orientação a objetos em PHP**
* aplicação de **Design Patterns simples**
* manipulação de dados com **SQL**
* controle de **transações no banco de dados**
* criação de interfaces web com **Bootstrap**

---

## 🧠 Conceitos utilizados no projeto

Durante o desenvolvimento foram utilizados alguns conceitos importantes:

* **Record Pattern** para manipulação de dados
* **Transaction Pattern** para controle de transações no banco
* separação entre **model, control e view**
* consultas dinâmicas ao banco de dados
